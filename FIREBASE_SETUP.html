2. 到 Firebase 控制台發布

  1. 用 Safari 開啟 Firebase 控制台，選擇 music-rainbow-kitchen-6c7fd。
  2. 進入「建置 / Build」→「Realtime Database」→「規則 / Rules」。不是 Cloud Firestore。
  3. 確認資料庫網址為 music-rainbow-kitchen-6c7fd-default-rtdb.asia-southeast1.firebasedatabase.app。
  4. 先保留原有規則備份。將規則編輯器全選，貼上上方完整 JSON（包含最外層 rules），按「發布 / Publish」。若介面不完整，可從 Safari 網站設定選「要求桌面網站」。

這份規則只開放 roomsV22 的受限匿名房間操作；其他路徑仍然鎖定。不要改成全域讀寫 true。匿名登入已啟用，不用重新設定。

3. 兩台裝置試玩

  1. 兩台裝置都開啟 V2.2 獨立測試版。
  2. 第一台選總共 4 位小朋友、簡單、此裝置 2 位，建立房間。第二台選此裝置 2 位，輸入相同房間代碼加入。
  3. 房主開始備料，兩台都按準備完成，房主開始營業。每台只顯示自己負責的食材。
  4. 食材由各裝置試聽；訂單旋律及背景音樂由房主播放。背景音樂持續低音量播放，與遊戲聲音分開調整。

使用限制

房主也是參加者，不需要老師端。請讓房主的 Safari 保持前景；目前沒有自動轉移房主。重新整理原分頁可嘗試恢復座位，關閉分頁可能失去匿名身分。房間效期約兩小時；逾期會停止存取，但不是自動刪除資料。房主離開關閉房間時會刪除房間。無姓名、聊天或歷史排行榜。

這是合作遊戲，房主裝置負責裁判；不是防作弊競賽伺服器。正式單機版本不受這份測試版影響。
