# 音樂彩虹廚房大作戰 V2.1.0

[開始遊戲](https://dandyluo416.github.io/music-rainbow-kitchen/)

設定 → 備料試聽 → 開始營業 → 聽訂單 → 選食材 → 確認放入 → 出餐。

- 每局選用集中音域並重新隨機分配；簡單每人相鄰兩個自然音，普通每人混合較低、中間與較高三音，困難四音含變化音。
- 同一食材的音高映射固定；整局沿用備料時的分配。再玩一次會重新進入備料。
- 食譜提示以高音譜號五線譜、四分音符顯示該張旋律，不附唱名／音名／食材。使用後該單全部分數乘 70%，重看不重複折減。Combo 與成功數保留。
- 已加入使用者提供的 enchanted forest kitchen 背景音樂。背景與遊戲聲音有獨立音量、靜音；試聽時背景先淡出到無聲，音符尾音結束一秒後才恢復。調整背景音量不會取消聽音保護。
- 每次確認後清除待選食材，確認按鈕顯示即將放入的名稱。重複音需再點一次食材。
- 暫停、離開分頁與結束都停止音樂；回合結束區分成功、逾時、答錯提交與未完成。

## 音域容量

A3～E5，A4=440 Hz。簡單最多 6 人，普通最多 4 人，困難最多 5 人；選單仍列 1～7 人，超過容量會提示且無法開始。預設四人簡單使用 C4～C5 八個自然音；三人簡單使用中央八度內連續六音。

## 檔案

`index.html` 已嵌入所有圖片、音訊與程式，可離線開啟；iPad 建議以 Safari 開啟網站。`Music_Rainbow_Kitchen_V2_1.zip` 包含可部署檔案、可編輯程式與素材、測試及版本說明。

## 驗證

1,945 項遊戲程式斷言通過，包含 1,500 張隨機訂單與所有 15 種有效人數／難度組合；另通過音訊混音器測試（淡出時序、連點、獨立音量、暫停、分頁隱藏）。這些是模擬 DOM／AudioContext 的測試，不是實聽或真機測試。

線上遠端 Chrome 已驗證三種難度、提示出餐、錯誤修正、兩分鐘回合結算及重新備料；1363×936 視窗無頁面溢出。詳細紀錄見 TEST_RESULTS.md。
