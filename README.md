# 音樂彩虹廚房大作戰 V1.0

## 開始遊玩

電腦：下載 index.html，以 Chrome 或 Safari 開啟即可。所有圖案、程式與音色都已內嵌，不需要安裝或外部網路資源。
iPad／電子白板：建議先上傳 GitHub Pages，使用 Safari／Chrome 開啟網址並橫向使用。iOS「檔案」的快速預覽不等於 Safari，可能不執行遊戲。

1. 選擇人數、難度與 2／3／5 分鐘，按「戴好廚師帽，開始」。這次點擊也會啟動音訊。
2. 每位學生站在自己號碼的工作台前。先試聽食材，認識音高與圖片。
3. 點訂單的「聽音」。訂單只提供空格數，不顯示答案。
4. 點下方食材會試聽並高亮，**不會直接填入**。按「確認放入」才加入下一格；同一食材可連續確認。
5. 可撤銷最後一格、清空、試聽自己製作的旋律。填滿且聽過訂單後才能出餐。
6. 普通／困難可點左側訂單切換；每張訂單的料理內容各自保留。切換時清除尚未確認的食材。
7. 答錯不扣分，保留料理供修改；按「再聽一次」比較順序。
8. 打烊後可再玩一次或返回設定。所有分數、訂單與 Combo 重設，不儲存歷史。

同一時間只保留一段音訊；任何新的試聽會停止前一段。背景切換會自動暫停，回來後按繼續。右上角也可手動暫停。部分 Safari 不支援全螢幕按鈕，可直接橫向遊玩。

## 設定與音樂規則

| 難度 | 每人食材 | 旋律長度 | 同時訂單 | 耐心 | 可用人數 |
|---|---:|---:|---:|---:|---|
| 簡單 | 2 | 2～3 音 | 1 | 65 秒 | 1～6 |
| 普通 | 3 | 3～4 音 | 2 | 85 秒 | 1～4 |
| 困難 | 4 | 4～5 音 | 3 | 105 秒 | 1～5 |

人數仍可選 1～7；超出音域容量時顯示原因並停用開始，絕不重複食材充數。
A3～E5 共 12 個自然音、20 個半音。3／4 人簡單為 6／8 種，普通為 9／12 種，困難為 12／16 種。四人困難包含 12 自然音與 C♯4、F♯4、G♯4、C♯5。變化音採升記號命名，無等音異名重複。

固定 Do：C=Do，B=Ti；下標是八度。困難可切換唱名、唱名＋音名、音名。
每個 MIDI 音高固定連結唯一原創 SVG 食材。頻率公式 440 × 2^((MIDI−69)/12)。
簡單使用 12 組不同泛音／起音設定的合成音色輔助辨識；並非真實樂器錄音。普通與困難全部使用相同設定。食材及訂單經過同一音訊函式，音色對應一致。
每音間隔 0.62 秒，聲音最長 0.49 秒。題目輪流使用各廚師負責的音高，盡量平均參與；一個人模式亦正常運作。

計分：正確 100 分＋首次提交正確 20 分＋耐心比例 0～20 分＋Combo 每次多 5 分（上限 30）。答錯／逾時中斷 Combo，既有分數不變。結算分開記錄「逾時訂單」與「答錯提交次數」，避免把後來修正成功的訂單重複算成失敗。打烊仍在等待的訂單不算逾時。
兩隊可使用相同設定；旋律隨機產生，並非完全相同題目。

## GitHub Pages 上線／替換

1. 解壓縮 ZIP。主要檔案是根目錄的 index.html；所有素材皆在其中，沒有額外圖片或音效資料夾。
2. 在你要放遊戲的 GitHub 儲存庫，選 Add file → Upload files，上傳 index.html 並提交。
3. 使用儲存庫根目錄部署時，Settings → Pages 選 Deploy from a branch、main、/(root)，儲存。若已啟用，直接替換檔案即可。
4. 等 Pages 更新後重新載入網站。若仍看到舊內容，重新整理或使用新的分頁開啟。
5. **若儲存庫根目錄原本是和弦研究室，請不要覆蓋它的 index.html。** 可將此遊戲放在 rainbow-kitchen/index.html 子目錄，網址使用原網站網址加 /rainbow-kitchen/；或使用獨立儲存庫。

本次僅交付檔案，沒有修改或部署任何現有網站。無 Firebase、帳號、遠端同步、追蹤或排名服務。

## 測試與限制

見 TEST_RESULTS.md。自動化驗證使用 Node.js 與模擬 DOM／AudioContext，不能代替瀏覽器與教室實測。
本次沒有可用的瀏覽器測試通道；尚未進行真實 Chrome、iPad Safari、電子白板的視覺／觸控／喇叭驗收。
主介面以平板與白板單頁排版為目標；手機窄螢幕（650px 以下）會改為可捲動，以避免裁切食材。
