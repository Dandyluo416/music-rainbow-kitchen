# 音樂彩虹廚房大作戰 V2.0

已依使用者指示將 V2 單檔版本提交到 main，供 GitHub Pages 發布。

遊玩網址：https://dandyluo416.github.io/music-rainbow-kitchen/

## 遊玩

設定人數與難度 → 備料試聽 → 開始營業 → 聽訂單 → 選食材 → 確認放入 → 出餐。備料階段不計時。

根目錄 index.html 已內嵌所有美術、樣式與音訊程式，可單獨下載開啟，不需要額外 assets。設定頁包含音色比較功能。

## 完整素材與備份

- Music_Rainbow_Kitchen_V2_Test.zip：原始完整測試包，內含分開的美術素材、音訊、程式、測試及 V1 備份；解壓縮後請維持資料夾結構。包內部署說明為發布前的歷史紀錄。
- V1_backup.html：可獨立開啟的原版；需要回復時將它複製成 index.html。Git 歷史也保留原版。
- CHANGES.md、TEST_RESULTS.md：開發時修改比較與測試紀錄。V2 測試程式在 ZIP 內，根目錄 test.cjs 為原有 V1 測試。

## 模式與驗收

簡單每人 2 音、不同音色（最多 6 人）；普通每人 3 音、統一音色（最多 4 人）；困難每人 4 音、含變化音（最多 5 人）。人數選單提供 1–7，超過 A3–E5 音域容量時會提示。

iPad Safari、電子白板觸控及教室喇叭實聽仍待真機驗收。既有程式與波形檢查不能替代這些測試。
