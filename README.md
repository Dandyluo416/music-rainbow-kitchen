# 音樂彩虹廚房大作戰 V2.0 測試版

這是從目前已發布的 V1 程式升級的可玩測試版。尚未取代 GitHub Pages 上的 V1，也尚未通過真實裝置與教室試聽驗收。

## 開啟與遊玩

1. 完整解壓縮 ZIP。保留 `index.html`、`v2.css`、`sound.js` 與 `assets/` 的相對位置。
2. Windows／Mac 可用 Chrome 直接開啟 `index.html`，不需安裝、不需伺服器、不需登入。iPad 建議用 Safari 開啟部署後的測試網址；檔案 App 的 HTML 預覽不等同 Safari。
3. 設定人數、難度、2／3／5 分鐘。困難模式可改用音名或唱名＋音名。
4. 按「下一步：備料試聽」。每位學生點自己工作台上的食材，反覆聽音。此時完全不計時、不產生訂單。
5. 按「準備好了，開始營業！」才開始倒數、產生客人訂單。
6. 點訂單與「聽音」→ 點食材（只選取與試聽）→「確認放入」。同一食材可以重複確認放入。
7. 填滿並聽過訂單後才能「出餐」。可以撤銷、清空或試聽已組好的料理；答錯保留內容、不扣既有分數。
8. 打烊後查看成績。「再玩一次」會歸零並重新進入備料；「返回設定」可換設定。切換到背景時，正式回合自動暫停。

## 音域與人數

固定 Do；數字標示八度。A3～E5 有 12 個自然音、20 個半音。

| 模式 | 每人食材 | 可用人數 | 同時訂單 | 音色 |
|---|---:|---|---:|---|
| 簡單 | 2 | 1～6 | 1 | 固定音高對應不同合成樂器 |
| 普通 | 3 | 1～4 | 2 | 柔和鋼琴 |
| 困難 | 4 | 1～5 | 3 | 柔和鋼琴 |

設定仍提供 1～7 人。超過音域容量會提示調整並停用開始按鈕，絕不重複音高充數。四人困難為 12 自然音＋4 變化音。

## 教師音色比較

設定頁底部的「音色比較室」，或直接開啟 `audio-lab.html`。12 個按鈕固定播放 A4，讓音高不干擾音色比較。`assets/instrument-audition.wav` 是同一合成器產生的可離線比較音檔。請先在教室喇叭試聽，確認音量與辨識度。

## GitHub Pages 部署（先測試，確認後才取代 V1）

本次沒有修改遠端 main 分支，也沒有覆蓋線上 V1。

若要先發布獨立測試網址：在儲存庫新增 `preview-v2/` 資料夾，將本包根目錄的 `index.html`、`v2.css`、`sound.js`、`audio-lab.html`、`.nojekyll` 以及整個 `assets/` 放入；Pages 完成部署後，測試網址會是原網站網址後加 `preview-v2/`。原根目錄 V1 保持不動。本次交付尚未執行這項上傳。

確認 V2 後：將上述檔案上傳至儲存庫根目錄，取代根目錄 `index.html`。維持 Pages 的 main / root 設定，等部署完成後重新整理並檢查四張圖片與音訊。

回復 V1：將 `backup/V1.0/index.html` 放回根目錄即可；V1 的美術與音訊原本都內嵌在該 HTML。建議在 GitHub 先保留 V1 tag／commit。

## 檔案

- `index.html`：保留 V1 遊戲邏輯，新增備料流程與動畫觸發。
- `v2.css`：V2 美術、動畫、各尺寸排版。
- `sound.js`：原創 12 音色合成器；遊戲不需要下載 WAV。
- `assets/`：原創廚房、20 食材、4 角色×5 表情、盤子／木牌／料理／星星圖集、比較 WAV。
- `backup/V1.0/`：改版前原檔及測試文件。
- `CHANGES.md`、`TEST_RESULTS.md`、`AUDIO_RESULTS.json`：比較與驗收紀錄。
- `ART_PROMPTS.md`：素材生成方式、提示與圖集索引。
- `test.cjs`：`node test.cjs` 執行流程回歸測試（模擬 DOM、AudioContext）。
- `verify-audio.cjs`、`verify-audio.py`：先 Node 產生波形，再 Python＋NumPy 分析。`audio-check-data/` 是可重建的測試暫存，不包含在部署包。

無外部字型、遠端圖片、追蹤器或音效 CDN；成績不跨回合儲存。
